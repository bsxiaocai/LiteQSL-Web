# v1.3.0 更新日志

> 发布日期：2026-06-21

## 数据与兼容性

- 数据库中的 QSO 日期和时间统一保存为 UTC
- 手动录入可选择北京时间或 UTC
- 访客表格可配置显示北京时间或 UTC
- 修复月度和年度统计对 `YYYYMMDD` 日期格式的错误比较
- 新增可重复执行的数据库版本迁移

## ADIF

- `FREQ` 和 `FREQ_RX` 按 ADIF 标准使用 MHz
- 使用 `QSL_SENT`、`QSL_RCVD` 和电子确认字段
- 增加 `ADIF_VER`、动态程序版本和 `SAT_MODE`
- 保留对旧版 LiteQSL-Web 非标准频率字段的导入兼容

## 工程质量

- 统一应用版本来源
- 删除未使用的查询函数和前端导入
- 增加时区、ADIF 往返和数据库迁移测试
