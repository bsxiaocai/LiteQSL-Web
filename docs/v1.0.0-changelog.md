# LiteQSL-Web v1.0.0 版本发布说明

**发布日期：** 2026-05-29  
**版本号：** v1.0.0  

---

## 版本概述

LiteQSL-Web v1.0.0 是首个正式发布版本，提供完整的业余无线电 QSL 通联日志与卡片收发管理功能。系统基于 FastAPI + SQLite 构建，界面简洁现代，适用于个人或小集体台使用。

---

## 核心功能

### 公共查询模块

- **呼号查询** — 其他友台可通过呼号查询通联历史与卡片收发状态
- **最近通联列表** — 首页展示最新通联记录，支持分页与多维筛选
- **QRZ 跳转** — 所有呼号支持点击跳转到 QRZ.com 查询页面

### 管理后台模块

- **管理员登录** — 安全的登录机制，支持首次登录强制改密
- **手动录入 QSO** — 逐条录入通联记录，频率自动识别波段
- **记录编辑** — 支持编辑已有 QSO 的全部字段
- **记录删除** — 支持删除错误或重复记录

### QSO 类型系统

支持四种 QSO 类型，适配不同通联场景：

| 类型 | 标签 | 说明 |
|------|------|------|
| `NORMAL` | 一般通联 | HF/VHF/UHF 常规通联 |
| `SAT` | 🛰 卫星通联 | 支持上下行频率 + 卫星名称 |
| `REP` | 📡 中继通联 | 支持输入输出频率 + 频差计算 |
| `EYEBALL` | 👀 Eyeball通联 | 线下面对面交流，频率/模式可选 |

### 数据导入导出

- **ADIF 导入** — 支持标准 `.adi` / `.adif` 文件批量导入，含重复检测
- **ADIF 导出** — 支持导出为 ADIF 格式，兼容主流软件
- **CSV 导出** — 支持导出为 CSV 格式，兼容 Excel（UTF-8 BOM）

### QSL 卡片状态管理

支持五种状态：

| 状态 | 说明 |
|------|------|
| 无法考证 | 无法确认通联真实性 |
| 未发送 | 卡片尚未发送 |
| 已发送 | 卡片已发送 |
| 无需发送 | 无需交换卡片 |
| 电子确认 | 通过电子方式确认 |

### Silent Key (SK) 支持

- 支持标记已去世的业余无线电操作员
- 列表中呼号后显示 `[SK]` 标识
- 可在录入或编辑时勾选

## 频率与波段系统

### 自动波段识别

- 覆盖 160m ~ 23cm 共 14 个 ITU Region 3 业余频段
- 输入频率后自动识别波段（如 `14.270` → `20m`）
- 前端实时提示识别结果

### 频率显示

| QSO 类型 | 显示格式 |
|----------|----------|
| 一般通联 | 单频率，如 `14.270 MHz` |
| 卫星通联 | `145.850 ↑ / 436.795 ↓` |
| 中继通联 | `439.600 (-5.0MHz)` |
| Eyeball | 可为空 |

## 安全特性

- **bcrypt 密码哈希** — 使用 bcrypt 算法（rounds=12）存储密码
- **登录频率限制** — IP 级别防暴力破解，5 次失败后锁定 10 分钟
- **SQL 注入防护** — 全部查询使用参数化占位符
- **路径穿越防护** — 备份文件名校验，防止目录遍历攻击
- **反向代理兼容** — 正确处理 X-Forwarded-For / X-Real-IP 头

---

## 用户体验

- **Toast 通知系统** — 操作成功/失败/警告的统一提示
- **Loading 状态** — 表单提交时显示加载动画，防止重复点击
- **前端实时校验** — 日期、时间、RST 等格式实时校验
- **密码强度指示器** — 修改密码时实时显示强度
- **移动端适配** — 响应式布局，小屏设备可用
- **双时区显示** — 同时显示北京时间与 UTC 时间

---

## 数据库备份与恢复

- 支持一键备份数据库
- 支持下载备份文件
- 支持从备份恢复（自动创建安全备份）
- 备份文件存储在 `data/backups/` 目录

```

├── data/                     # 数据库（自动生成）
```

## 数据库字段

### 通联记录表（logs）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | 主键，自增 |
| `call` | TEXT | 对方呼号 |
| `qso_date` | TEXT | 通联日期（YYYYMMDD） |
| `time_on` | TEXT | 通联时间（HHMMSS） |
| `freq` | TEXT | 主频率（MHz） |
| `band` | TEXT | 波段（自动推导） |
| `mode` | TEXT | 模式（SSB、CW、FT8 等） |
| `qso_type` | TEXT | QSO 类型 |
| `tx_freq` | TEXT | 发射/上行频率（MHz） |
| `rx_freq` | TEXT | 接收/下行频率（MHz） |
| `sat_name` | TEXT | 卫星名称 |
| `rst_sent` | TEXT | 发送的 RST 信号报告 |
| `rst_rcvd` | TEXT | 接收的 RST 信号报告 |
| `qsl_status` | TEXT | 卡片状态 |
| `is_sk` | INTEGER | Silent Key 标识（0/1） |
| `comment` | TEXT | 备注 |
| `created_at` | TIMESTAMP | 记录创建时间 |

## 快速开始

### 安装

```bash
git clone https://github.com/bsxiaocai/LiteQSL-Web.git
cd LiteQSL-Web
pip install -r requirements.txt
```

### 启动

```bash
python run.py
```

### 访问

| 页面 | 地址 |
|------|------|
| 公共查询页 | http://localhost:8000/ |
| 管理后台 | http://localhost:8000/admin |

### 默认账号

| 字段 | 值 |
|------|------|
| 用户名 | `admin` |
| 密码 | `Admin123!` |

首次登录后系统将强制要求修改用户名和密码。

---

## 已知限制

1. **SK 标识导出：** ADIF 标准无 SK 字段，暂不支持导出
2. **Eyeball 导入：** ADIF 无 Eyeball 类型，导入时归类为 NORMAL
3. **多用户：** 当前仅支持单管理员账户
