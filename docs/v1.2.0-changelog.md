# v1.2.0 更新日志

> 📅 发布日期：2026-06-05

## 🎉 版本亮点

v1.2.0 是一个重要的架构升级版本，主要完成了前端模块化重构、高级搜索功能和多项体验优化。

---

## ✨ 新增功能

### 呼号配置功能

- 管理后台新增「系统设置」区域，支持修改操作员呼号和站点名称
- 访客界面标题自动显示为 `{呼号} {站点名称}` 格式
- 搜索框 placeholder 动态显示当前呼号
- 呼号自动转大写存储
- 默认值为 `BH7GUL` 和 `QSL & Log Management`

### 高级搜索与筛选

- 新增日期范围筛选（起始日期 ~ 结束日期）
- 新增 SK 状态筛选（正常/SK）
- 导出功能支持筛选条件（ADIF/CSV）
- 后端 API 支持 `sort_by` 和 `sort_order` 排序参数

### 自动日期时间

- 录入表单自动填充今天的日期和当前 UTC 时间
- 新增「今天」按钮，一键填充当前日期
- 新增「现在 UTC」按钮，一键填充当前 UTC 时间
- EYEBALL 类型切换时自动填充日期、清空时间

### 密码重置脚本

- 新增 `reset_password.py` 脚本，支持在服务器端重置管理员密码
- 支持列出所有用户、重置指定用户密码、重置首次登录状态

---

## 🏗️ 架构改进

### 前端模块化重构

**改进前：**
- `admin.html` 1777 行，所有 JS 内联
- `index.html` 478 行，与 admin 大量重复代码
- 无构建流程，无法使用 ES Module

**改进后：**
- `admin.html` 776 行（-56%），仅保留 HTML 结构
- `index.html` 169 行（-65%），仅保留 HTML 结构
- 使用 ES Module 组织代码，消除重复

**新增的 JS 模块结构：**

```
static/js/
├── common/           # 公共模块
│   ├── utils.js      # 工具函数
│   ├── constants.js  # 常量定义
│   ├── formatters.js # 格式化函数
│   ├── pagination.js # 分页组件
│   ├── clock.js      # 时钟组件
│   └── index.js      # 统一导出
├── public/           # 公开页面
│   └── app.js        # 主逻辑
└── admin/            # 管理后台
    ├── app.js        # 主入口
    ├── auth.js       # 登录认证
    ├── qso-form.js   # QSO 表单
    ├── qso-table.js  # 记录表格
    ├── edit-modal.js # 编辑弹窗
    ├── import-export.js # 导入导出
    ├── backup.js     # 备份管理
    └── settings.js   # 系统设置
```

### Tailwind CSS 本地化

- 将 Tailwind CSS 从 CDN 引用改为本地文件
- 无需依赖外部 CDN 服务
- 页面加载速度更快
- 离线环境也能正常使用

## 🔧 升级指南

### 从 v1.1.0 升级

1. 拉取最新代码：
   ```bash
   git pull origin main
   ```

2. 重启服务：
   ```bash
   python run.py
   ```

3. 如果遇到登录问题，可使用密码重置脚本：
   ```bash
   python reset_password.py
   ```
